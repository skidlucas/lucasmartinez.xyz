# lucasmartinez.xyz

my personal cv site. minimalist design, built with astro.

## stack

- astro
- typescript
- vanilla css
- bun
- deployed on cloudflare workers (static assets)

## dev

```sh
bun install
bun dev
bun run check   # typecheck
bun run build   # production build
```

## i18n

- `/` - english
- `/fr/` - french
- `/kr/` - easter egg (noindex)
